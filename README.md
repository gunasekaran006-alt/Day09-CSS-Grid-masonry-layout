# 📌 Pinterest Clone - Masonry Layout

A lightweight and responsive **Masonry Layout** (Pinterest-style) created using modern **CSS Grid**. This project demonstrates how to handle varying image heights in a clean, organized grid structure without using complex JavaScript libraries.


## ✨ Features
- **CSS Grid Power:** Uses `grid-template-columns` and `grid-row: span` for the masonry effect.
- **Fully Responsive:** Adapts to different screen sizes easily.
- **Clean UI:** Rounded corners and smooth image scaling with `object-fit: cover`.
- **Fast Loading:** No heavy external libraries like Masonry.js.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure.
- **CSS3:** Grid Layout, Flexbox, and Custom Styling.

## 📂 Project Structure
- `index.html` - The core structure of the grid.
- `style.css` - Custom styles and grid logic.
